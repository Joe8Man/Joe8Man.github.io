# 六宗戰鬥代表造型與完整人物顯示

- 戰鬥新增六張 4×4 圖集，每張前八格為男修（跑步四格、出招四格），後八格為女修（跑步四格、出招四格）。同宗各階共用一套代表性戰鬥造型；讀取不到圖集時沿用既有的宗門服飾四姿勢。
- 大地圖以角色實際穿著的 `outfit_id` 顯示既有宗門與階級的全身立繪。未穿宗門服飾時顯示原本地圖角色。
- 角色頁紙娃娃以現有服飾立繪呈現完整人物，四個裝備欄位保留，服飾名稱在人物下方。衣閣更換服飾會使角色頁和大地圖同步刷新。
- 新圖集集中於 `assets/combat-v1/sect-combat-*.webp`，原始生成 PNG 的來源見專案產出 `sect-combat-sources.json`。`node scripts/pack-combat-assets.cjs <manifest>` 可增量重打包，不重建未列入清單的圖集。
- 宗門代表圖集沒有獨立的倒地及施法幀；戰鬥以同宗的攻擊姿勢組合施法、受擊及防禦。六宗服飾階級圖仍用原本資料，存檔、能力值與衣閣價格不變。
