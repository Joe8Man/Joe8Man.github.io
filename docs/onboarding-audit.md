# 入門與破境可達性檢查

淬鍊原本存在於舊探索頁的百藝修行，新 Phaser 世界缺少可見入口。現在選單與角色裝備頁均可開啟原煉器坊，沿用材料消耗、必定成功、五階上限與屬性加成，不建立第二套資料。

發現並修正：即時秘境將未通關深度退回外圍，導致首次深處試煉無法結算。新增深度選單與入口驗證，第一次即可在符合境界／戰力時挑戰，勝利記入所選深度。

資格逐項對應：修為與小境（洞府）；殘劍（青州野外）；首領三次及指定深處（秘境深度選單）；兩門功法小成（角色功法，宗門藏經閣／坊市古籍／分支尋訪）；煉體與養神各二（角色修習）；淬鍊一階（煉器坊）；靈晶／殘片（秘境、機緣與煉器懸賞）；感悟（機緣、論道、分支探索與掉落）。分支尋訪功法入口補在秘境選單。六大世界妖王不是破境條件。

新手引導由現有存檔推導目標，不新增強制進度或資源獎勵；開場看完或略過後，煉氣角色會看到引導。大地圖與選單可重看。破境面板新增淬鍊、秘境、養神煉體及坊市入口。

驗證：29 項新手／真實淬鍊／各境資格／首次深處通關檢查，179 項世界首領回歸、Phaser 客戶端與物品圖像語法檢查通過。
