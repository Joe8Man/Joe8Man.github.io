# Phaser 客戶端整合

## 可見畫面

`assets/engine/client.js` 是全頁 Phaser Canvas 呈現層。涵蓋標題、創角、修煉、宗門、背包、坊市、角色／功法、仙緣錄、設定、存檔、一般對話與舊探索／切磋視窗。畫面文字、按鈕、圖像、捲動與地圖由 Phaser GameObjects、Container、Camera、Mask 呈現。沒有以整頁截圖代替互動介面。

大地圖使用百分比座標對接正式行旅規則，Phaser 負責地形、建築、人物精靈、金色主角辨識、拖曳鏡頭、雙指／滾輪縮放及定位；到達才由原命令扣精力、推進日期並觸發 NPC 因果。大地圖保留小型「選單」，其他頁使用共用導覽。

自由除妖、秘境與 NPC 交鋒沿用現有 Phaser 碰撞與招式模型；血條文字、技能、暫停／返回、結算及觸控搖桿由新 Phaser 呈現層控制。其他既有 Phaser 場景可以作為動態 Canvas texture 出現在共用視窗。

## 與舊程式的界線

這是呈現層遷移，尚未刪除所有舊 HTML 產生函式。舊介面樹保留在不可見位置作為相容的 view model／動作目標，Canvas 元件讀取語意內容及 disabled 狀態，再呼叫原來的動作驗證；修為、道具交易、宗門資格、NPC 關係與存檔仍只有原來的一套正式資料。這層相容橋接降低遷移時重寫經濟規則的風險，也意味後續仍可將各頁的 view model 從 DOM 產生器移成純資料模組。

文字／數字／下拉選取使用短暫的瀏覽器輸入面板，以支援手機鍵盤；OAuth、檔案選取及下載仍由瀏覽器處理。沒有改變登入提供者、認證權限、雲端覆寫確認或存檔格式。

## 操作與效能

- Phaser RESIZE 適配橫直向；內容遮罩與捲動不影響頂部／導覽。
- 拖曳不觸發按鈕；捲出內容區的按鈕不接受滑鼠操作。
- 畫面模型簽章改變才重建介面，載入圖像及嵌入 SVG 共用快取。
- 隱藏頁面停止主迴圈並清除搖桿輸入。
- Canvas 按鈕同步語意控制列，支援鍵盤及輔助工具；舊介面根節點隱藏於可及性樹。
- `data-phaser-screen`、`data-phaser-paused`、`data-phaser-running` 提供場景診斷。

## 驗證

全部 15 組 Node 測試通過，包含 12 項 Canvas 動作／可見性／輸入檢查、94 項 world 檢查、32 項 field 檢查、20 項帳號／遊客入口檢查及原戰鬥／經濟／宗門套件。

瀏覽器驗證標題至創角、修煉／宗門／背包／角色／山河切換、仙緣錄數值、Phaser 地圖呈現、戰鬥場景與技能控制。手機直向／橫向另用隔離預覽頁測試，不包含在公開檔案中。OAuth 憑證及真實使用者雲端資料未代為操作。

## 手機比例修正

主介面由 Scale.RESIZE 改成明確的 Scale.NONE 尺寸同步，使用 visualViewport／window 的 CSS 像素寬高同步 renderer、canvas 顯示尺寸與鏡頭，監聽可視區 resize、視窗 resize 與 orientationchange。舊介面的 1100px 資料樹不再影響主畫布尺寸。

戰鬥場景維持 960×660 的遊戲座標及等比例 FIT，橫直向切換同步 parentSize。樣式移除強制拉滿 canvas 的寬高，改以 max-width／max-height 限制並置中；移除 FIT 的 margin，避免和 flex 置中重複位移。直向保留等比例留邊，不裁掉戰鬥區。

針對舊橫向控制列 display:contents 外層無盒子的情況，直接隱藏所有舊控制子元素，Phaser HUD 仍讀取原本狀態，不會同時顯示兩套技能或搖桿。

瀏覽器實測同一 iframe 連續切換 393×852、852×393：主畫布 buffer 與顯示尺寸一致，兩軸比例誤差 0。直向戰鬥顯示 393×270.1875（960×660 等比例），Canvas margin 為 0；舊技能及搖桿的 visibility 均為 hidden。field 32、world 94、client 12 項檢查通過。

### 按鈕美術與更新穩定性

所有 Canvas 操作共用程序繪製的青玉、古金切角按鈕：雙層細框、漸層底色、雲紋與按壓回饋。圖樣以兩倍解析度快取，不需額外下載。戰鬥技能使用劍、身法、丹藥圖示，招式名與耗氣／冷卻分開顯示；搖桿採同一套金玉配色。

地圖資源和行旅訊息、戰鬥氣血／真氣／冷卻只更新原有節點。被動修為或倒數不會銷毀重建控制列；換頁、暫停和視窗尺寸改變才重建版面。控制物件及每個後加入的子節點明確排除大地圖攝影機，避免地圖平移時再次畫出控制列。`data-ui-builds` 可檢查重建次數。

### 分類頁籤與有界頁面

角色分為總覽、裝備、功法、法寶、修習；總覽以肖像及六格數值顯示狀態，裝備與功法以卡片開啟詳情。法寶圖鑑改為五格，不再逐張縱向展開。背包保留全部／裝備／丹藥靈物／材料篩選與只看未穿戴，改用每頁有限格數；坊市分常備、法器、珍藏、古籍。宗門以原本的功能頁籤直接呈現，衣閣與藏經閣使用卡片。

其他內容依實際可用高度換頁，長文字依實際換行結果拆頁，簡短操作並排。操作仍引用原始節點及驗證器；裝備詳情不會因為點卡片就卸裝，物品仍先打開原本交易詳情。底部導覽有獨立實色區域，內容不會畫到導覽列下。縮短視窗會重新計算頁數並保留有效頁碼。

### 搖桿回饋

內圈與方向標記跟隨手指，最大位移 32px，輸入向量使用圓形限制，避免斜向加速；3px 死區避免漂移。同一時刻只有一根手指持有搖桿，另一根可施放技能。放開、移出、取消觸控、失焦、換向、切畫面或背景化都送出零輸入並回正；冷卻數字更新不會重新建立搖桿。
