# 標題入口與齒輪設定

標題頁固定四字單欄「一念入道」，不再使用受高度限制而折欄的直書文字。提供「帳號登入」與「遊客遊玩」兩種入口；遊客按鈕由遊戲主程式接管，不依賴 Supabase 或網路登入服務初始化。

遊客可創角或保留並接續本機角色。選擇遊客時，即使瀏覽器曾記住帳號，亦不以該帳號使用線上功能；稍後明確開啟帳號功能才恢復帳號模式。延遲到達的登入事件不會取消遊客選擇。現有 PKCE／OAuth、認證儲存、雲端使用者限制及手動覆寫確認保持不變。帳號登入後，無論新裝置是否已有本機角色，都提供查看雲端與建立／接續本機角色的選擇。

右上角與「更多」以齒輪「設定」取代直接存檔入口。設定包含：

- 存檔與備份：原有匯出、匯入、重新輪迴與返回設定。
- 帳號與雲端存檔：獨立對話框，提供登入、查看雲端、手動上傳、還原前備份及登出；不必先切至線上道友頁。

不新增匿名雲端帳號，不自動上傳、不自動覆寫。全部認證及資料政策沿用既有設定；沒有資料庫結構或權限變更。

驗證：entry 測試 20 項涵蓋遊客創角、接續、設定入口、記住帳號時的遊客隔離、延遲登入事件、雲端選擇與登出保留進度。手機預覽驗證直排、兩個入口、遊客創角、齒輪及存檔頁；OAuth 提供者憑證登入不以使用者帳號代為測試。
