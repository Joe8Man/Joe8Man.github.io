# Distinct sect wardrobes

Built-in imagegen artwork replaces shared dyed robes. Assets: `assets/wardrobe-v4/{sword,academy,demon,ice,beast,pill,masters-male,masters-female}.webp`. Independent palettes, cuts, and materials are used for each sect. `SECT_COSTUMES` selects each gender, rank and pose. Existing wardrobe IDs, prices, and purchases are retained. Cached previews live at `assets/wardrobe-v5/` and are built by `scripts/build-wardrobe-previews.cjs`. No runtime color filters or artificial chest emblems.

## Prompt set

### sword

Use case: stylized-concept. Production xianxia RPG sprite atlas, TRUE TRANSPARENT background. Exactly FIVE equal columns and TEN equal rows, portrait 1:2 canvas, target 1536x3072. All 50 full-body figures isolated in their own cells with generous transparent gutters. NO touching, NO crossing cell boundaries, swords must fit inside cell. No text, no UI, no labels, no badges, no symbols pasted over chest, no background. Beautiful detailed hand-painted realistic Chinese fantasy illustration, natural faces and cloth textures.
ONE sect design throughout this atlas: Jiutian Sword Sect: moon-white linen and deep NAVY silk, sharp narrow crossed collars, clean straight vertical hems, practical sword belts, elegant restrained silver edging. Minimal gold. Scholar swordsman, crisp fitted silhouette.
Rows 1-5: same handsome adult MALE with long black hair, rank ascending. Rows 6-10: same beautiful adult FEMALE with long dark hair, rank ascending. Same outfits and rank progression for both genders, adapted naturally to body.
Five ranks in each gender's five rows: outer disciple plain fitted short tunic and trousers; inner disciple ankle-length crossed-collar robe; core disciple layered fitted combat outfit and distinctive shoulder structure; elder voluminous high-quality wide-sleeve ceremonial coat and ornate stole; sect master grand full-length cape, elaborate GOLD or SILVER crown appropriate to sect, most luxurious layered silhouette. Make rank differences visible in cut, sleeves, hem and headwear, not just recoloring.
Columns 1-5 in EVERY ROW: 1 standing ready facing RIGHT holding straight silver jian diagonally; 2 overhead sword wind-up facing right; 3 horizontal sword thrust right; 4 follow-through sword slash facing right; 5 lotus seated meditation hands on knees with NO sword.
Preserve identical clothing across poses within each row. Head and feet fully in frame. Fit all parts in cell, including swords. Full alpha transparency and clean edges. Principal palette, materials and silhouette must follow THIS sect's description rather than generic white-and-green robes. Small detailed physical embroidery is fine, but absolutely no floating icons or artificially overlaid chest emblems.
