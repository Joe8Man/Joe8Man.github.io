# 一念九州後端

專案：`jiuchmwjziiehdfcoazh`，免費方案，東京。

`schema.sql` 是已部署資料結構的來源紀錄。遠端 migration history 由 Supabase 管理。

私人存檔只允許擁有者讀寫，最大 250 KB。前端以 revision 比對更新，遇到另一裝置更新時停止覆寫，改由玩家選擇下載或重新確認上傳。切換帳號不自動上傳、下載或公開角色。

道友名帖是自願公開給已登入玩家的顯示資料，不包含電子郵件、私有存檔或資源。境界為玩家自行提供，不作排名依據。

非同步切磋由資料庫 RPC 執行，以公開名帖的架勢進行同階投影對戰，雙方均為 100 氣血。穩守克強攻、強攻克凝神、凝神克穩守，每回合雙方同時出手。沒有資源獎勵或排行榜，避免本機存檔進入競爭經濟。對手收回名帖後無法再被挑戰。

登入使用 GitHub OAuth。需在 Supabase 啟用 GitHub provider，並設定正式網址與回呼白名單。玩家登入和開發者登入 Supabase 後台是獨立的設定。

公開名帖新增 `realm`（可空，0–10）、`gender`、`outfit_id`、`equipment`、`sect`、`rank`。舊名帖仍可切磋，但需更新後才能歸入境界與顯示完整外觀。只存放已穿戴的裝備 ID，不包含背包、Email 或私有存檔；前端從本地遊戲字典取得裝備名稱。

Phaser 擂台只播放 RPC 的逐回合結果。同境界與全部境界為查詢篩選；跨境切磋仍使用公平投影，不建立依玩家上傳數值決定的排名。
